## 6. Submission options: notes for certification

> Brainitive is a client for a Brainitive server. To test it, sign in to Brainitive Cloud:
> 1. Start the app and choose "Brainitive Cloud".
> 2. The sign-in opens in the default browser. Use the test account below and approve the app.
> 3. The browser returns to the app automatically.
>
> Test account: `<e-mail>` / `<password>` (a demo workspace with sample data; no purchase needed).
>
> Restricted capability `runFullTrust`: Brainitive is a desktop (Win32) app built with Tauri and WebView2. It needs full trust for global keyboard shortcuts, the system tray icon, the Windows Credential Manager (sign-in tokens) and the microphone for on-device voice capture.

**Before submitting:**
- Create the test account on brainitive.app with a demo workspace and some sample data.
- Turn off two-factor sign-in for it, so the testers can get in.
