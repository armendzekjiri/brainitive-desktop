## Manual checks (owner)

- macOS: download a file with "Ask where to save" on and off → `xattr -p com.apple.quarantine <file>`
  shows `0081;…;Brainitive;…`.
- `open "brainitive://open?url=/app/session/x"` and `…?url=/%61pp/session/x` → nothing happens (log:
  "deep link to another origin or an auth page ignored"); `…?url=/my-work` opens My Work.
- A link to another site in the app window (macOS): the browser opens it, the app stays on the page.
- Sign out while Quick Capture has text / a recording runs → both gone.
